There are 4 major layers in [[Linux]] Architecture 
- [[#Application Layer]] ^61b920
- [[#Shell]]
- [[#Kernel]]
- [[#Hardware]]

## Application Layer 
a layer which refers to the Application software used to utilize the **[[Operating system]]**
using Applications software like
- [[vscode]] 
- [[Terminal]]

## Shell 
shell is a layer which provide interface between Application layer and Kernal basically with the help of Shell we can interact with kernal using [[shell scripting]] language such as 
- [[bash]]
- zsh
- fish

## Kernel 
it's a heart of the [[Operating system]] which manage the [[Process]] and allocate the hardware resources efficiently while ensure security infact,
>[!info]- info 
>Linux is the kernal not **O.S** 


## Hardware 
it's a Component of an Computer which is tangible and utilize with the help of 
[[Operating system]] and Applications software
